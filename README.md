# 股票分析平台 (stock_quant_model_V3)

基于 Dash 的 A 股量化分析平台，提供个股分析、多因子训练、趋势分析、模拟炒股、市场概览、板块资金强度与交易日志等功能。

> **⚠️ 免责声明**：本项目仅供学习交流与个人娱乐，**不构成任何投资建议**，**禁止商业用途**。使用前请阅读[免责声明](#免责声明)与[许可证](#许可证)。

## 功能模块

| 页面 | 路由 | 说明 |
|------|------|------|
| 分析 | `/` | 个股 K 线 + 均线策略（双均线/SMA/EMA）回测、三重信号过滤（趋势/确认/ADX）、自动趋势线（摆动点连线支撑/阻力趋势线 + 水平支撑阻力位聚类 + 突破状态标注）、量化走势预测（概率化）、多信号共振面板、多周期（日/周/月/分钟线）、训练因子评分面板、股票标记、记事本 |
| 股票管理 | `/stock-management` | 自选股代码增删改查、自选分组（watchlist）管理 |
| 因子训练 | `/factor-training` | 自定义因子公式 → 预处理（去极值/标准化/中性化）→ IC/ICIR 检验 → LGBM 滚动训练 → 组合回测 → Excel 导出；训练完成的模型自动持久化（可自定义命名，按【ICIR/LGBM】分类管理，支持加载/删除），评分自动接入「分析」页 |
| 趋势分析 | `/trend-analysis` | RSI / 布林带 / MACD 背离 / 支撑压力位 / 斐波那契 / 自动趋势线 & 阻力线（短/中期摆动点连线支撑阻力趋势线 + 水平支撑阻力位，线端状态标注与信号） |
| 模拟炒股 | `/stock-game` | 股票交易小游戏：隐藏未来逐根揭示历史K线，收盘价成交模拟买卖（100股整手/T+1/佣金印花税过户费），MA/MACD/RSI/KDJ/BOLL/量比参数面板，资产曲线对比买入持有基准，结算按超额收益评段位 S/A/B/C/D；支持分钟线快节奏模式（60/30/15/5分钟+自动播放）与战绩持久化（排行榜/我的战绩，按账户隔离存SQLite） |
| 每日五面 | `/market-overview` | 指数全景 + 资金/情绪/技术/消息/国际五维度概览（支持 AI 点评）；盘前提醒卡片（交易日历/隔夜海外市场/A股复盘/今日新股/自选股异动/持仓关注，baostock 为主 tushare 补充 + Redis 每小时缓存） |
| 板块资金强度 | `/sector-fund-strength` | CLV 量价模型估算板块主力资金，抢筹/建仓/洗盘/出货分级 |
| 交易日志 | `/trading-journal` | 持仓流水、资金曲线、盈亏分析 |

多用户支持：注册/登录/改密，PBKDF2 密码哈希，各账户数据隔离。

自选股信号监控：后台线程每 5 分钟用 baostock 拉取自选股日线，检测双均线金叉持仓状态；页面右下角铃铛提示信号数量与明细（信号日/现价/持仓天数），并用分析页最近使用的三重过滤设置标注"✓过滤确认/✗被过滤"；扫描中显示实时进度条（已扫描数/百分比/当前股票/预计剩余时间）；多进程部署下通过文件锁保证只有一个扫描线程。

## 环境要求

- Python 3.10+（开发环境 3.14）
- Redis（本地 6379，用于 K 线缓存；未启动时自动降级直连数据源）
- tushare token（可选，见下方配置；不配置时使用免费的 baostock 数据源）

## 安装与启动

```bash
pip install -r requirements.txt
python run_app.py          # 默认 http://127.0.0.1:8050
```

首次运行会自动完成初始化，无需手动建库：
- 自动创建 SQLite 数据库（用户/自选分组/交易日志/模拟炒股战绩等表）
- 自动创建默认账号 `admin / admin123`（登录后请立即修改密码）
- 全市场股票代码可在「股票管理」页一键拉取

## 配置 tushare token

tushare 数据源需要 token（[tushare.pro](https://tushare.pro) 注册后，在「个人主页 → 接口 TOKEN」获取）。两种方式任选：

**方式一：环境变量（推荐，凭据不落盘）**

```bash
# Windows PowerShell（当前会话）
$env:TUSHARE_TOKEN = "你的token"
# Windows 永久
setx TUSHARE_TOKEN "你的token"
# macOS / Linux
export TUSHARE_TOKEN="你的token"
```

**方式二：配置文件**

```bash
copy config\config.example.yaml config\config.yaml   # Windows
# cp config/config.example.yaml config/config.yaml   # macOS / Linux
```

然后编辑 `config/config.yaml`，把 token 填入 `tushare.token`。该文件已被 `.gitignore` 排除，不会上传到 Git。

> 不配置 token 时应用照常启动，自动使用免费数据源 baostock（分钟线优先走 baostock）。完整配置项说明见 `config/config.example.yaml` 内注释。

## 注意事项

- 所有数据仅供参考，不构成投资建议。
- 自动趋势线：分析页「自动趋势线」卡片开启后，K线图自动绘制支撑趋势线（连接摆动低点，全程须位于价格下方）、阻力趋势线（连接摆动高点）并向右延伸约 10 根 K 线；水平支撑/阻力位由摆动点价格聚类生成（≥2 次触及才显示）；注释区标注每条线状态（支撑有效/逼近/已跌破，压制中/逼近阻力/已突破）。趋势线是几何事实，"趋势线必被尊重"并非统计定律，请结合量能与更大级别趋势判断。
- 分析页参数持久化：选股列表、数据源、日期范围、K线周期、均线参数、信号过滤设置、预测周期等会自动保存到浏览器 localStorage（Dash 组件原生 persistence），刷新页面或重启应用后自动恢复并按恢复的参数重算图表；按浏览器隔离，换浏览器/设备为默认值。
- 走势预测（概率化）：分析页「量化走势预测」卡片。输出为概率而非保证：N 步后上涨概率（GBM 解析概率 × 历史同状态经验频率混合）、触及自适应止盈/止损位的概率（蒙特卡洛路径模拟）、乐观/中性/悲观三情景；置信带 80%/50%。每个模型展示该股 walk-forward 回测的实测方向命中率、区间覆盖率、MAPE 与 P(涨) 校准差；方向命中 ≤50% 标注"≈抛硬币"；趋势/震荡状态感知——震荡市明确提示方向预测不可信。**不存在保证准确的预测模型，请结合回测指标理解预测。**
- 多信号共振：分析页选中股票后自动计算，整合项目内各模块方法论——因子模型横截面分位（权重 0.30）、价格/趋势均线+ADX 趋势状态（0.25）、MACD+RSI 技术动量（0.20）、CLV 收盘位置资金流（0.15，与板块资金强度页同源）、三重过滤后均线策略持仓状态（0.10）；缺失维度自动按剩余权重归一。
- 信号过滤：分析页「信号过滤」卡片提供趋势过滤（收盘价须在趋势均线上方）、信号确认（金叉条件连续 N 日成立，无未来函数）、ADX 过滤（低于阈值视为震荡市不入场）三重买入过滤；离场信号一律放行。图上灰色空心点为被过滤的原始买入信号，注释区显示过滤前后对比。
- 因子模型持久化：训练完成自动保存到 `cache/factor_models/`（pkl 数据 + json 元数据）；重启后自动加载最近保存的模型，可在因子训练页「已保存模型」或分析页「使用模型」下拉中切换/删除。
- 分钟线优先走 baostock（tushare stk_mins 对低积分账户限 1 次/分钟）。
- 因子训练的 LGBM 依赖 lightgbm，未安装时自动回退 sklearn GradientBoosting；两者都未安装则该功能不可用。
