# 使用教程

面向新用户的完整上手指南。安装与配置（含 tushare token）见 [README](../README.md)，本文只讲"怎么用"。

---

## 一、启动应用

### 方式一：双击启动脚本（推荐 Windows 用户）

项目根目录自带 `启动股票分析平台.bat`，双击即可：

1. 若程序**尚未运行**：会启动服务，并在服务就绪后**自动打开浏览器**（约几秒到半分钟，视首次数据初始化而定）。
2. 若程序**已在运行**：不会重复启动，直接打开浏览器进入页面。

> ⚠️ 双击后弹出的**黑色命令行窗口是服务进程，必须保持开着**（可以最小化）；关闭它 = 停止服务，页面将无法访问。

### 在桌面创建快捷方式

1. 右键点击项目根目录下的 `启动股票分析平台.bat`；
2. 选择 **发送到 → 桌面快捷方式**（Windows 11 需先点「显示更多选项」）；
3. 以后双击桌面图标即可一键启动，浏览器自动打开 `http://127.0.0.1:8050`。

可选：按 `Win + R` 输入 `shell:startup` 回车，把快捷方式放进打开的文件夹，可实现**开机自动启动服务**（登录 Windows 后服务自动就绪，首次打开浏览器访问即可）。

### 方式二：命令行启动

```bash
# 首次使用先安装依赖
pip install -r requirements.txt

# 启动（默认 http://127.0.0.1:8050）
python run_app.py
```

若项目根目录存在 `.venv` 虚拟环境，启动脚本会自动优先使用它。

### 首次启动会发生什么

- 自动创建 SQLite 数据库（用户、自选分组、交易日志、模拟炒股战绩等表），**无需手动建库**；
- 自动创建默认账号 `admin / admin123`，登录页会给出提示；
- 股票列表初始为空，需要在页面中添加（见下文「股票管理」）。

## 二、登录与账号

- 首次登录使用默认账号 `admin / admin123`，**登录后请立即点击顶栏「改密」修改密码**；
- 也可以在登录页切换到「注册」标签创建自己的账号；
- **每个账号的数据完全隔离**：自选股分组、股票标记、记事本、交易日志、账户资金、模拟炒股战绩互不可见；
- 顶栏按钮：分析页专属「刷新」、全局「改密」与「退出」。

## 三、各页面使用指南

顶栏导航共 8 个页面，按典型使用顺序介绍。

### 1. 分析（首页 `/`）—— 个股技术分析主战场

左侧边栏自上而下：

| 区块 | 用法 |
|------|------|
| 选择股票 | 多选下拉，可同时对比多只股票；选项来自你添加过的代码 |
| 数据源 | Tushare（推荐，需 token）/ Baostock（免费，无需注册），切换后图表清空重查 |
| 添加代码 | 输入单个代码（如 `600519.SH` 或 `600519`）点「插入」入库 |
| 查询所有代码 | 查看当前账号已入库的全部代码 |
| 日期选择 | 开始/结束日期 + K线周期（日/周/月/60/30/15分钟） |
| 策略参数 | 短期/长期均线周期（默认 5/20），配合 SMA/EMA 均线策略回测 |

选好股票后点顶栏「刷新」绘制图表。右侧功能区：

- **均线策略回测**：图上标注金叉/死叉买卖点，附夏普比率等绩效指标；
- **信号过滤**：趋势过滤（价格须在趋势均线上方）+ 信号确认（金叉条件连续 N 日成立）+ ADX 过滤（过滤震荡市）三重买入过滤，灰色空心点为被过滤信号；
- **自动趋势线**：自动绘制支撑/阻力趋势线与水平支撑阻力位，标注每条线的状态（支撑有效/已跌破等）；
- **量化走势预测**：N 步后上涨概率、触及止盈/止损位概率（蒙特卡洛模拟）、三情景与置信带，并展示该模型 walk-forward 回测的实测命中率——**输出是概率不是保证**；
- **多信号共振**：自动整合因子分位、趋势状态、技术动量、资金流、策略持仓五个维度给出综合信号；
- **因子评分**：加载因子训练页保存的模型后，对当前股票打分；
- **股票标记 / 记事本**：把关注的股票打标记快速回访，随手记笔记。

> 分析页的参数（选股、日期、周期、过滤设置等）会自动保存在浏览器 localStorage，刷新或重启后自动恢复。

### 2. 股票管理（`/stock-management`）—— 自选股仓库

- **添加股票**：输入代码（支持逗号/空格分隔批量添加）→ 点「获取名称」自动补全中文名 → 点「添加」；
- **自选股分组**：左侧新建分组（如"白酒""半导体"），用「快速添加股票到分组」把代码归组；列表页可按分组过滤；
- 列表支持搜索、分页、编辑代码/名称、删除；
- 加入分组的股票会被后台信号监控线程扫描（见第六节）。

### 3. 因子训练（`/factor-training`）—— 量化因子工厂

1. 用表达式自定义因子公式（基于行情量价字段）；
2. 选择预处理（去极值/标准化/中性化）后做 **IC / ICIR** 检验，看因子预测能力；
3. 通过检验后用 **LGBM 滚动训练**并做组合回测（未装 lightgbm 自动回退 sklearn）；
4. 训练完成自动持久化（可自定义命名），在「已保存模型」中加载/删除；
5. 模型评分自动接入「分析」页的因子评分面板；支持导出 Excel。

### 4. 趋势分析（`/trend-analysis`）—— 技术面工具箱

输入代码后逐项查看：RSI、布林带、MACD 背离、支撑压力位、斐波那契回撤、自动趋势线与阻力线（短/中期摆动点连线，线端状态标注与信号提示）。

### 5. 模拟炒股（`/stock-game`）—— 复盘演练小游戏

**核心机制：每局随机抽取一段历史时间段**，行情逐根揭示，你看不到"未来"，在未知中练习决策。

开始一局：

1. 左侧选择股票、数据源、K线周期（日线/周线适合慢节奏；60/30/15/5分钟为快节奏）；
2. 选择游戏长度：60 根（速战）/ 120 根（标准）/ 250 根（一年马拉松）；
3. 选择初始资金（10 万 / 50 万 / 100 万），点「开始新游戏」。

对局中：

- 图表从游戏开始线（虚线）左侧的历史上下文开始，逐根向右揭示，**游戏区间之后的行情被隐藏**；
- **成交规则**：只能以"当根收盘价"市价成交；买入须 100 股整手；T+1（当根买入下一根才可卖）；佣金万 2.5（最低 5 元）+ 卖出印花税万 5 + 过户费万 0.1；非整手只能一次性清仓；
- **操作按钮**：自定义买入 + 快捷买 ¼/半/全仓；自定义卖出 + 卖一半/全部清仓；
- **推进**：「下一根」单步走、「快进 5 根」跳着走、「自动播放」按选定速度自动揭示（快节奏分钟线推荐）；
- 图下方「当前技术参数」面板随行情逐根更新（MA/MACD/RSI/KDJ/BOLL/量比/成交额），供决策参考；
- 随时可点「结算」结束，走完全程再推进也会自动结算。

结算与战绩：

- 按**超额收益**（你 vs 首根收盘全仓买入持有的基准）评定段位 S/A/B/C/D，并给出最大回撤、平仓胜率、手续费合计等明细；
- 战绩自动计入「排行榜」（全用户按超额收益排名）与「我的战绩」（含个人汇总：总局数/平均超额/跑赢基准占比/最佳一局）。

### 6. 每日五面（`/market-overview`）—— 市场全景

- 选日期、数据源后点运行，生成指数全景与**资金/情绪/技术/消息/国际**五维度概览 + 五因子雷达图与市场温度；
- 每个面板可开启 **AI 点评**：首次使用在页面内的 AI 设置中填入服务商（如 DeepSeek）、API Key、模型名，点「测试连接」通过后保存。Key 只保存在本地 `cache/ai_settings.json`，不会上传；
- 含盘前提醒卡片：交易日历、隔夜海外市场、A股复盘、今日新股、自选股异动等（数据每小时缓存）。

### 7. 板块资金强度（`/sector-fund-strength`）

CLV 量价模型估算各行业板块主力资金流向，按**抢筹/建仓/洗盘/出货**四档分级展示，辅助判断资金聚集方向。

### 8. 交易日志（`/trading-journal`）—— 你的实盘记账本

- 记录每笔买入/卖出（代码自动补全名称，可设交易类型与标签、备注买卖理由）；
- 首次使用先「设置初始资金」，出入金走「资金流水」；
- 自动汇总：当前持仓表、资金曲线、盈亏分析、每日盈亏统计，支持个股 K 线联动查看买卖点；
- 「刷新价格」拉取最新行情计算浮动盈亏；支持导出 CSV 备份。

## 四、自选股信号监控（后台自动）

- 应用运行期间，后台线程**每 5 分钟**拉取自选分组内股票的日线，检测双均线金叉并按分析页最近的三重过滤设置标注"✓过滤确认/✗被过滤"；
- 有信号时页面**右下角铃铛**提示数量，点开看明细（信号日/现价/持仓天数）；
- 仅检测你加入自选分组的股票；多开程序时通过文件锁保证只有一个扫描线程在工作。

## 五、常见问题（FAQ）

**Q：双击 .bat 窗口一闪就没了？**
多半是 Python 环境没装好。用方式二在命令行运行 `python run_app.py` 看具体报错；确认已 `pip install -r requirements.txt`，且 Python 为 3.10+。

**Q：浏览器没有自动打开？**
手动访问 [http://127.0.0.1:8050](http://127.0.0.1:8050)。端口被占用时服务会启动失败，关掉占用 8050 端口的程序后重试。

**Q：没装 Redis / Redis 没启动有影响吗？**
能正常使用，只是 K 线不做缓存，每次查询直连数据源，速度慢一些（日志会有提示）。装好并启动 Redis 后自动启用缓存。

**Q：没配置 tushare token 能用吗？**
能。应用自动使用免费数据源 baostock（无需注册）。想用 tushare（数据更全、积分接口更多）按 README 配置 token 后在页面数据源下拉切换。

**Q：分钟线拉不到 / 很慢？**
分钟线优先走 baostock（免费，历史从 2020 年起）；tushare 的分钟接口对低积分账户限 1 次/分钟，频繁请求会被限速。

**Q：模拟炒股提示"数据不足"？**
该股票历史太短（次新股）或所选游戏长度超过可用数据，换一只股票或缩短游戏长度即可。

**Q：忘记密码怎么办？**
目前没有自助找回功能（密码只存哈希）。可以注册一个新账号使用；**不建议**删除数据库文件，那会清空所有账号的数据。

**Q：排行榜里能看到别人的真实持仓吗？**
不能。排行榜只展示模拟炒股的结算战绩（收益率/超额/段位），所有持仓、资金、交易日志均按账号隔离存储在本地。
